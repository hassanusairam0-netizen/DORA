# DORA — The Building Blocks of Life

A 6-slide Grade 7 science presentation on **D**NA, **O**rganelles, **R**eproduction and **A**verage size.

Presented by Usairam, Jacob, Ryan, and Colin.

## How to present

Open `index.html` in any web browser (it needs internet for the fonts).

- **→ / Space / click right side**: next slide
- **← / click left side**: previous slide
- **F**: full screen

`slides/` holds the source of each slide, including speaker notes in each `<aside>`.
